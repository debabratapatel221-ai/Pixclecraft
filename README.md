# Pixclecraft

A fresh, original browser-based voxel sandbox prototype inspired by classic block-building games.

## Run locally
Because this project uses JavaScript modules, serve the folder with a local web server (for example VS Code Live Server) rather than opening `index.html` directly.

## Publish with GitHub Pages
Upload the contents of this folder to the repository root. In Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**.

## Controls
- WASD: move
- Mouse: look around (click Enter World first)
- Space: jump
- Shift: sprint
- Left click: break block
- Right click: place selected block
- 1–6: select block

This is an early foundation, not a complete Minecraft clone. It uses original procedural pixel textures and a simple generated voxel landscape. Three.js is loaded from jsDelivr, so an internet connection is required.
